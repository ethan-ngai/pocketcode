# AGENTS.md

Shebang is a TanStack Start-based SMS-REPL supporting Java and Python execution aimed at convenient code execution for those without access to WiFi or data.

## Tech Stack

- TanStack Start
- Cloudflare Workers and Sandbox
- Twillo
- Better Auth
- Neon Postgres

## Conventions

- Always document all code using `/skills/jsdoc-best-practices` as guidance. The skill can be found in the repo root.
